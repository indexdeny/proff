## Physical Scope Rules

1. Introduces `project_state/decisions/` for standalone architectural decision record documents.
2. Introduces `.git/` representing the independent local Git repository.
3. Adds `governance/git_policy.md` and `.agents/rules/03-git-checkpoints.md`.
4. Pre-existing case data (`tg_save/`) and backup archives (`R0_BACKUP.zip`) are preserved on disk but strictly untracked by Git.
5. All future pipeline modules and reference library directories remain deferred to their respective roadmap phases.
